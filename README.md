# Perfect Player · 完美球员

纯网页篮球生涯模拟：创建自己的球员，从选秀走进常规赛和季后赛，把训练、事件、舆论和一场场球，打成一条完整生涯。

打开就能玩，不用安装，也不依赖虎扑 App。

生涯事件现在围绕身体状态、球队地位、场上默契和场外收入展开。试用会增加真实轮换分钟，恢复安排可以限制出场时间，临时效果按球队比赛场次结束。工资、拍摄收入和恢复、团队活动支出进入同一套模拟账本；旧档从启用账本之后开始记录。

获得大当家话语权或达到高默契后，可以在赛季中向管理层建议更契合球风的教练，每队每季一次。教练复用五种球队体系，直接模拟和观看比赛都读取其节奏、攻防和出手倾向。赛前提供白底球员照片对比与本场安排。

实现与验证见 [生涯事件交付记录](tools/artifacts/career-event-release.md)。

## 2026-10-04 阵容与 PC 生涯界面

- 现代开局采用 2026-10-03 NBA 官网 30 队、620 人的训练营名单；建球与比赛共用一个名单来源，修正旧建球池中的转会归属。训练营名单会继续裁减，尚不是最终常规赛名单。
- 历史开局按 2003-04、2010-11、2016-17 开赛日归属校对，共 89 支球队、1,310 人。2003 年为 29 队，2004 年加入夏洛特；同步修正赛程、分区和年代选秀。
- 主菜单加入球员舞台，赛季面板集中展示分钟计划、风险、默契和账本，赛前放大双方人物对比。技能、成就和传承面板统一适配深色主题。
- 阻止重复启动与重复比赛回调；读档后旧回调失效，模拟失败可以重试，已经完成的比赛保留。旧生涯继续采用自身存档的模拟联盟。

验证：35 项执行检查通过，Chrome 实测观看与直接模拟、三场轮换效果到期、商业收入与团队支出、默契换帅和存读档。来源、估值边界与具体结果见 [本轮交付记录](tools/artifacts/pc-roster-release.md)。人物舞台目前采用标明“虚拟形象”的渲染图片。

## 相对原版多了什么

本项目基于 [zyz9408 / Perfect Player](https://zyz9408.github.io/perfect-player/nba-perfect-player.html) 继续做。原版已经有建档、选秀、训练、快速赛季和基础生涯框架；这边主要补强「看球」和「过日子」两块：

- **观看体验**：关键场可以真的看下去——文字回合播报、俯瞰球场跑动，以及更清楚的比分与数据反馈
- **赛季过程**：联盟排名会跟着赛季走；重要场次开打前能看到双方首发
- **事件与叙事**：赛季事件更丰，训练相关选择也能攒出后续资源；跨赛季的宿敌、名宿、中国线、更衣室等故事线会认人认队
- **荣誉与成就**：赛季末按媒体讨论的思路发奖；生涯节点可解锁成就，并带一点传承底子
- **休赛期动向**：会汇总联盟转会里总评最高的一批变动，不只是静静换赛季
- **手感与文案**：球员得分节奏、直播文案等做过一轮调校，减少怪词和过猛手感
- **部署方式**：面向 GitHub Pages 可直接玩，不再绑死虎扑活动壳
- **双模式与存档**：现役生涯、2003 / 2010 / 2016 传奇年代可选，两种模式各自保留续玩存档
- **传奇联盟**：按三个年代的开赛日名单进入联盟，2003 年为 29 队，2004 年扩军至 30 队；名单人数随历史资料和休赛期变化。总评按目标赛季表现、年龄与生涯阶段校准，缺少样本的球员标注估值，原始 NBA 2K 数值另存，并支持多位置排阵
- **季后赛数据**：赛前查看完整阵容与评分，我方每场赛后展示双方主要球员和全队数据
- **年代成长**：年轻历史球员会朝合理生涯峰值成长，年代选秀不会再混入现役新秀池
- **球队话语权**：成为球队老大后，每个休赛期可向管理层建议裁掉一名队友
- **传承五级**：十条传承路线全部开放到 5 级，第 5 级有实际属性或球队效率效果

玩法骨架仍是「球员第一人称生涯」，不是总经理模拟器。
