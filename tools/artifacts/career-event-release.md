# 生涯事件、收支与教练联动交付记录

四类主要状态已经接到正式游戏：身体状态、球队地位、场上默契和场外收入。新事件有 11 个场景、22 个选项；轮换、宿敌和恢复各有三段经历，另有拍摄与团队活动。每个选项最多影响两类状态，提示写明金额、分钟变化和持续场次。

选择会进入真实比赛计算。试用增加轮换分钟；医疗安排设置出场上限；负荷与默契影响攻防，负荷也进入伤病概率。临时效果按球队比赛逐场结算，在指定场次后结束。任务反馈来自实际出场、分钟、得分和球队胜负，不能把文案当作已经发生的比赛动作。

模拟收入包括合约工资与场外收入，支出包括恢复支持和团队活动。工资按常规赛球队比赛支付，伤病或禁赛缺阵也照常支付；季后赛不会再次领取常规赛工资。一整季结算精确累计到年薪，重复比赛键不会重复付款或消耗效果。金额是游戏经济规则，并非真实 NBA 球员合同；旧档只记录启用账本后的收入。

球队大当家、已有名单话语权，或默契达到 6/10，可以在赛季中提出一次主教练建议。候选根据球员属性展示球风契合度，管理层采纳后立即切换球队体系，费用由球队承担。五种体系复用已有实现；原有休赛期打法选择保留。本轮把制服组影响落在主教练，没有引入单独的总经理、助教和球探人事系统。

赛前面板展示双方焦点球员、白底照片、自己的球衣立绘、近期表现和本场安排。自建球员立绘与真人照片有明确区别。3D 人物仍需要模型素材，本轮交付照片与立绘展示。

新增逻辑集中在 [生涯事件模块](../../assets/js/perfect-player-career-events.js)，核心通过明确的调用点接入；没有新依赖，也没有保存旧函数后再层层包装的机制。

| 行为 | 定位 |
|---|---|
| 事件定义、选择、效果期限、收支、任务、教练与赛前界面 | `perfect-player-career-events.js` 中对应的命名函数 |
| 轮换计划与实际分钟 | 核心的 `getPlayerRotationPlan` / `getPlayerRotationMinutes` |
| 攻防、直接模拟与正规比赛结算 | 核心的 `getCareerTeamGameModifiers` / `quickSimAllGames` / `simOnePlayoffGame` |
| 教练体系写入 | `perfect-player-mod-v4.js` 的 `setTeamSystem` |
| 观看比赛中的分钟限制与球队体系 | `perfect-player-live-sim.js` 的 `userWantedOn` / `buildBlueprint` / `pickShotType` |
| 保存与读档 | 核心的 `manualSaveGame` / `manualLoadGame` / `renderSeasonScreenDOM` |

验证已经执行：

- 32 个 `tools/test-*.mjs` 全部通过。新增检查逐一执行 22 个选项，检查资金不足时整项选择不生效、效果到期、重复结算、缺阵工资、全年工资守恒、教练解锁、真正比赛节奏变化、读档保留和旧档数值。
- 分钟限制测试运行完整直接模拟与完整观看引擎；观看引擎还检查关键时段不会突破医疗上限。教练选择用相同随机种子的比赛样本比较换帅前后，两种引擎都体现节奏改变。
- Chrome 中通过正式页面操作，拍摄收入增加 US$180,000、负荷增加 2；团队活动支出 US$35,000 后余额为 US$145,000；建立配合后解锁教练建议，选择七秒进攻使真实球队体系改变。
- Chrome 的正式保存、读档后，余额、收入、临时效果、教练、OVR 和属性保留，验证页显示 `saveRestored: true`。
- Chrome 中恢复事件设置 22 分钟上限后，直接模拟得到 21 分钟，完整观看引擎得到 22 分钟。
- 正常赛季流程中，前三场真实工资累计为 US$54,878；试用选择使轮换计划从 23 分钟变为 29 分钟，并显示三场期限。
- 手机视口 390/320 已检查；游戏文档宽度与滚动宽度相同，赛前照片与四类状态已查看实际画面。测试结束恢复默认视口。

保存验证发现并修复了两个原有问题：手动保存曾调用读档后的页面重建函数，导致重新启动模拟；读档重建的战绩栏曾固定显示 0。现在保存只写当前检查点，战绩栏读取已保存的真实胜负与场均数据。新增检查实际调用保存与战绩渲染函数，确认保存不会重启模拟，并核对 2 胜 1 负、66.7% 与真实场均数字。

可复核：[执行检查](../test-career-event-effects.mjs)、[浏览器验证页](../browser-career-event-smoke.html)。浏览器测试使用独立本地端口与测试角色，未覆盖用户原端口的生涯。
