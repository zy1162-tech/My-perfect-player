## 界面变化

保留篮球暖色主题，将主要内容放在白色卡片上，淡化地板纹理。桌面入口采用双列，最大内容宽度由 560 扩展至 1040；手机继续单列。球员卡片放大头像和评分、压缩左侧已选名单，并保留底部滚动空间以避开传承悬浮按钮。赛季战绩使用深色记分条，数据数字采用等宽排列。球员卡片支持 Enter/Space，使用明确的选中状态和聚焦样式。

## 有证据的代码优化

阵容分配的每个递归分支原先都重新筛选、排序同一名单，现在每个位置先排序一次，再排除已占用球员。删除重复的替补排序及重复用户去重，保留最优多位置分配和玩家第六人的行为。

复现了训练缓存问题：FIN 从 80 变为 89 而 OVR 不变时，原缓存仍返回 80。球员与联盟实力基线的缓存键现纳入属性，回归结果返回 89。一次本地对照中，30 队、10 轮冷阵容计算由 186.75ms 变为 39.36ms；这是单次采样，不是跨设备性能承诺。

静态资源精确查询版本命中时仍直接用缓存；新版本未命中则先访问网络，失败才使用忽略查询的离线回退。避免在线混用旧脚本与新页面。保留离线功能及缺失必需资源时安装失败的保护。
